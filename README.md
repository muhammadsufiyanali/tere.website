# Tere — Ride Sharing Business Website

A multi-page, fully responsive business website for **Tere**, a carpool / ride-sharing app. Built with plain HTML, CSS and JavaScript, so no build step is needed.

## Pages
- **Home (`index.html`):** animated hero with typing headline, floating cards, a "get the app" SMS form, partner marquee, animated stats, how it works, benefits, testimonials slider, FAQ and a call to action
- **About (`about.html`):** story, values, milestone timeline, team and careers
- **Services (`services.html`):** services, safety features, and a pricing table with a monthly/yearly toggle
- **Drive with Tere (`drive.html`):** earnings calculator and a 3-step driver application form with validation
- **Contact (`contact.html`):** contact form with validation, contact details and a Help Center FAQ

## Highlights
- Animated sticky header with:
  - entrance animation
  - sliding hover indicator
  - shrink-on-scroll effect
  - scroll progress bar
  - announcement bar
  - full-screen animated mobile menu
- Preloader, scroll-reveal animations, counters, hover effects, WhatsApp and back-to-top buttons
- Form submissions are stored in `localStorage` (demo, no backend)

Open `index.html` in a browser, or use VS Code Live Server.
